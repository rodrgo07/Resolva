# Hardening e Blindagem de Segurança

## 1. Princípios Invioláveis
- Zero Shell / PowerShell / CMD / Bash.
- Zero eval() / exec() / SQL Injection.
- Redaction automática de segredos em logs estruturados JSON.
- Scanner recursivo contra Prompt Injection (ExternalContentSanitizer).
- Proteção Global contra Loops e Spam (GlobalActionRateLimiter).
