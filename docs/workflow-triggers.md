# Workflow Triggers Engine (Fase 33)

## 1. Tipos de Triggers Suportados
- **TIME / SCHEDULE**: Horários fixos e dias da semana.
- **EVENT**: Eventos do EventBus (POMODORO_COMPLETED, TASK_OVERDUE, CALENDAR_EVENT_UPCOMING, etc.).
- **CONNECTIVITY / DEVICE**: Dispositivo conectado, desconectado, modo online/offline.
- **AGENT_RECOMMENDATION**: Sugestões proativas estruturadas pelo Resolva Agent.
- **MANUAL**: Disparo manual pelo usuário via Desktop, Mobile ou Smart Widget.
