# RESOLVA Design System (Desktop & Mobile)

## 1. Tokens de Design
O sistema utiliza tokens CSS para desacoplamento de cores e flexibilidade temática:
- --background: Cor de fundo primária.
- --surface: Superfície de cards e modais.
- --border: Bordas translúcidas de glassmorphism.
- --text-primary / --text-secondary: Tipografia de alto contraste.
- --accent / --accent-glow: Destaques luminosos e estados de foco.
