# Adaptive Workflows & Dynamic Scoring (Fase 34)

## 1. Sistema de Scoring
Pontuação determinística explicável baseada em pesos configuráveis:
score = urgency_score + deadline_score + contextual_score + routine_score + prediction_score - interruption_penalty

## 2. Adaptação Dinâmica
Workflows adaptam o número de blocos e etapas conforme a janela de tempo disponível (ex: Pomodoro de 25m vs Bloco de 50m).
