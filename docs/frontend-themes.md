# Sistema de Temas do RESOLVA

## Temas Suportados
1. **RESOLVA / Default**: Paleta original azul/roxa profunda com glassmorphism.
2. **Dark**: Minimalismo escuro com contraste otimizado para sessões longas.
3. **White**: Tema claro elegante com contraste refinado.
4. **Red**: Acentos carmesim energéticos com base neutra.
5. **Green**: Acentos esmeralda com foco em bem-estar e produtividade.
